MimiClaw 项目代码全景分析

1. 项目概览

MimiClaw 是一个基于 ESP32-S3 的嵌入式 AI 智能体固件。它利用 FreeRTOS 进行任务调度，通过 C 语言实现了一套完整的 ReAct (Reasoning and Acting) 循环，使其能够像 Claude 一样进行思考和行动。

  • 核心语言: C (ESP-IDF 框架)
  • 操作系统: FreeRTOS
  • 关键功能: 消息总线、LLM 代理调用、工具执行、多渠道通信 (Telegram/WebSocket/Serial)

5. 关键代码解析

入口函数 app_main

位于 main/mimi.c，负责系统的“冷启动”。它按顺序初始化 NVS -> SPIFFS -> WiFi -> 消息总线 -> 各个服务任务。

智能体循环 agent_loop

位于 main/agent/agent_loop.c。这是一个无限循环的任务，它不断检查消息队列。一旦收到消息，它就会维护一个对话上下文，并根据 LLM 的返回结果决定是继续调用工具还是输出最终回复。

消息总线 message_bus

位于 main/bus/message_bus.c。使用 FreeRTOS 的 xQueueSend 和 xQueueReceive 实现。它解耦了通信协议（Telegram/WebSocket）与业务逻辑（Agent），使得增加新的通信方式变得非常简单。
