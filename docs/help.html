🚀 快速开始

1 硬件连接

使用 USB Type-C 数据线将 ESP32-S3 开发板连接到电脑。请务必连接标有 USB 的接口（原生 USB），而非 COM/UART 接口。

请在此处插入：开发板连接示意图，标注出正确的 USB 接口位置

2 确认串口

连接成功后，在电脑设备管理器（Windows）或终端（macOS/Linux）中确认设备已识别。

# macOS/Linux
ls /dev/cu.usb*
# 预期输出: /dev/cu.usbmodem11401

🔑 Token 配置流程

Telegram Bot Token 获取

1. 在 Telegram 中搜索 @BotFather，点击 Start。

2. 发送 /newbot 命令，按照提示输入机器人名称（Name）和用户名（Username）。

3. 获取红色的 HTTP API Token。

请在此处插入：BotFather 对话截图，圈出 API Token

LLM API Key 获取

支持 Anthropic (Claude) 和 OpenAI (GPT) 及其兼容模型（如 DeepSeek/Moonshot）。

  • Anthropic: 访问 console.anthropic.com 创建 API Key。
  • OpenAI: 访问 platform.openai.com 创建 API Key。
  • Moonshot/DeepSeek: 访问各自的开放平台获取 Key 和 Endpoint URL。

🦅 飞书 (Feishu) 接入详解

MimiClaw 支持飞书企业自建应用，通过 WebSocket 模式实现内网穿透，无需公网 IP。

1 创建企业自建应用

登录 飞书开放平台开发者后台，点击“创建企业自建应用”。

填写应用名称（如“MimiClaw助理”）和描述，点击创建。

请在此处插入：飞书开放平台创建应用页面截图

2 添加机器人能力

在左侧菜单点击“添加应用能力”，找到“机器人”卡片，点击“添加”。

请在此处插入：添加机器人能力页面截图

3 配置权限

进入“权限管理”，搜索并开通以下三个核心权限：

  • im:message (获取用户发给机器人的单聊消息)
  • im:message:group_at_msg (获取群聊中 @机器人的消息)
  • im:message:send_as_bot (以应用身份发送消息)

⚠️ 配置完成后，必须点击页面顶部的“创建版本”并发布，权限才会生效！

请在此处插入：权限配置页面截图，高亮上述三个权限

4 开启 WebSocket 长连接

进入“事件订阅”页面：

  1. 不要配置请求网址 (Request URL)。
  2. 找到配置页下方的“长连接模式 (WebSocket)”，点击开启。
  3. 在“添加事件”中搜索并添加 im.message.receive_v1 (接收消息)。

请在此处插入：事件订阅页面截图，箭头指向 WebSocket 开关和事件列表

5 获取凭证并配置设备

回到“凭证与基础信息”页面，复制 App ID 和 App Secret。

请在此处插入：凭证页面截图，遮挡部分 Secret

连接开发板串口，输入以下命令完成配置：

mimi> set_feishu_config cli_a1b2c3d4e5f6 secret_1234567890abcdef
mimi> restart

重启后，MimiClaw 将自动连接飞书云端。

💻 常用 CLI 指令参考

通过串口工具（如 Putty, SecureCRT, idf.py monitor）连接设备后使用。

命令 说明 示例
wifi_set 设置 WiFi 账号密码 wifi_set MyHome 12345678
set_tg_token 设置 Telegram Token set_tg_token 123456:ABC...
set_feishu_config 设置飞书 AppID 和 Secret set_feishu_config cli_xxx sec_xxx
set_api_key 设置 LLM API Key set_api_key sk-ant-xxx
restart 重启设备 restart
